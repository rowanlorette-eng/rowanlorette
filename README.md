# MVP Video Hosting Platform

**Описание проекта:**  
Этот проект представляет собой минимально жизнеспособный видеохостинг (MVP), созданный полностью с нуля. Он предоставляет пользователям возможность загружать, публиковать и просматривать видео через современный веб-интерфейс без рекламы.

---

## Архитектура

- **Backend:** Go (Golang)
- **Frontend:** HTML, CSS, JavaScript
- **База данных:** SQLite (через драйвер `modernc.org/sqlite`)
- **Транскодинг видео:** ffmpeg → HLS (HTTP Live Streaming)
    - Видео делится на сегменты (`seg001.ts`, `index.m3u8`)
- **Thumbnail:** пользователь может выбрать кадр для обложки видео, который сохраняется в базе данных

## Принцип работы загрузки видео

### 1. Загрузка видео
- Пользователь загружает видеофайл через веб-интерфейс
- Видео сохраняется во временное хранилище

### 2. Подготовка метаданных
До начала обработки видео пользователь может:
- изменить название видео
- выбрать момент времени для превью

### 3. Генерация превью
- На выбранном таймкоде генерируется thumbnail
- Для извлечения кадра используется FFmpeg

### 4. Транскодирование видео
- Видео отправляется на обработку
- Выполняется транскодирование в формат HLS:
    - создаётся `index.m3u8`
    - видео делится на сегменты `.ts`

### 5. Завершение обработки
- Превью сохраняется в базе данных
- Видео помечается статусом `ready` и становится доступным для просмотра
